# Mitmachen

Python 3.11+, virtuelle Umgebung und `pip install -e '.[dev,radio]'` verwenden. Vor einem Pull Request `ruff check .`, `pytest` und `python -m build` ausführen. Tests dürfen keine Funkverbindung öffnen und keine echten API-Schlüssel benötigen. Neue Fähigkeiten müssen die Public-Sperre, Kanalregeln, Quellenwahrheit und Sendepausen beibehalten. Keine privaten Kontakte, Logs oder Konfigurationsschlüssel einchecken.
